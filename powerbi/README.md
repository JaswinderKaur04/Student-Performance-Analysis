# Power BI Dashboard

This folder contains the Power BI dashboard created for the Student Performance Analysis project.

## Dashboard Pages

- Executive Overview
- Factor & Score Relationships
- Performance & Pass Rate Analysis

## Key KPIs

- Total Students: 100,000
- Pass Rate: 77.39%
- Average Exam Score: 61.95
- Average Attendance: 84.63%

## Dashboard Analysis

The dashboard analyzes:

- Student performance distribution
- Pass and fail rates
- Study hours and exam scores
- Attendance and exam scores
- Previous GPA and exam scores
- Time management and exam scores
- Pass rates across study-hour groups
- Pass rates across attendance groups
- Sleep quality
- Device availability
- Parent education

## Tools Used

- Power BI
- DAX
- Power Query
